# meta-project

> 一个关于「怎么用 AI 做项目」的项目。或者说，项目的项目——元项目。

## 这是什么

我每周和 AI 一起写代码、做工具、搭系统。过程里踩了不少坑，也攒了一些管用的方法。这个仓库就是把这些经验——协同模式、流程设计、翻车教训——从各个具体项目里捞出来，提炼成可以跨项目复用的东西。

## 里面有什么

| 文件 | 是什么 |
|------|--------|
| `patterns.md` | 可复用的工程模式（问题 → 方案 → 适用条件） |
| `learnings.md` | 每次翻车后的经验碎片 |
| `design-log.md` | 关键设计决策的记录与追溯 |


## 为什么叫「元」

因为它的内容不是关于某个具体领域的，而是关于**怎么做项目本身**。它不回答"React 的 useEffect 怎么用"，它回答"当我跟 AI 说要做个功能，怎么确保 AI 不跑偏"。
